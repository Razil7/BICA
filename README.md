# ToM-антифрод: агент с моделью убеждений жертвы

Учебно-исследовательский проект команды 08-554 (курс по BICA, направление ToM-2). Агент по архитектуре перспектив Самсоновича явно ведёт убеждения жертвы (He-Now(V)), цель манипулятора (OTHER(S)∘GOAL∘OTHER(V)) и доступ жертвы к проверке (Access(V)) и проверяется на реальных замерах убеждений людей (датасет PUPPET).

**Главный итог:** на всём тестовом наборе (781 диалог, Gemma 4 26B) агент не точнее прямого предсказания той же модели — средняя ошибка 15.3 против 15.0; показана эквивалентность с точностью ±1 пункт (p = 0.013). План анализа записан до запуска.

## Запуск

```bash
pip install pandas numpy scipy requests matplotlib tqdm nbformat nbclient ipykernel
py tools/run_nb.py ToM_antifraud.ipynb ToM_antifraud.ipynb
```

Ключи API: скопируйте `secrets/keys.env.example` в `secrets/keys.env` и впишите свои. Пока ноутбук выполняется из кэша, ключи не тратятся.

Исходные данные (PUPPET, MentalManip, CraigslistBargain) в репозиторий не входят: ноутбук скачивает их сам из открытых источников в `tom_work/data/`.
