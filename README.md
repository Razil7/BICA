# ToM-антифрод: агент с моделью убеждений жертвы

Учебно-исследовательский проект команды 08-554 (курс по BICA, направление ToM-2). Агент по архитектуре перспектив Самсоновича явно ведёт убеждения жертвы (He-Now(V)), цель манипулятора (OTHER(S)∘GOAL∘OTHER(V)) и доступ жертвы к проверке (Access(V)) и проверяется на реальных замерах убеждений людей (датасет PUPPET).

**Главный итог:** на всём тестовом наборе (781 диалог, Gemma 4 26B) агент не точнее прямого предсказания той же модели — средняя ошибка 15.3 против 15.0; показана эквивалентность с точностью ±1 пункт (p = 0.013). План анализа записан до запуска.

## Запуск

```bash
pip install pandas numpy scipy requests matplotlib tqdm nbformat nbclient ipykernel
py tools/run_nb.py ToM_antifraud.ipynb ToM_antifraud.ipynb
```

Ключи API: скопируйте `secrets/keys.env.example` в `secrets/keys.env` и впишите свои. Пока ноутбук выполняется из кэша, ключи не тратятся.

Исходные данные (PUPPET, MentalManip, CraigslistBargain) в репозиторий не входят: ноутбук скачивает их сам из открытых источников в `tom_work/data/`.

### Пилот He-Now(V) с цитатами

Из корня проекта `python tools/audit_perspectives.py` воспроизводит исходные метрики, ход детектора и форму для разметчиков. Исходные датасеты должны лежать в `tom_work/data/`.

Команда `python tools/run_perspective_pilot.py --size 30` воспроизводит пилот на первых 30 диалогах dev из имеющегося кэша. Для новых запросов укажите `--budget N`, где N — предел HTTP-попыток, включая повторы. Ключи берутся из тех же источников, что в ноутбуке. При нескольких ключах диалоги делятся между ними, каждый диалог закрепляется за одним ключом. Результаты находятся в `tom_work/results/perspectives_dev_30/`, проверки минимальных пар — в `tools/test_perspectives.py`.

### Парный тест доступа к информации

[Протокол и результаты](ЭКСПЕРИМЕНТ_ДОСТУПА.md). Из корня BICA выполните `python tools/run_access_pairs.py --local --budget 0` для воспроизведения локальной Gemma из кэша. Для новых локальных ответов нужен сервер LM Studio на 127.0.0.1:1234 с моделью google/gemma-4-e4b и положительный бюджет. Без `--local` используется отдельный кэш облачной Gemma. Частичный прогон сохраняется в partial.jsonl; полные метрики записываются только при наличии всех ответов.
