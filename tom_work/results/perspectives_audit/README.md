# Независимая разметка позиции человека

Каждый из двух разметчиков заполняет собственную копию annotation_blank.csv до обсуждения ответов. В 75 строках приведены утверждение, предыдущая реплика для контекста и собственные слова человека. Числа dialogue и turn служат для сопоставления строк.

В колонке stance выберите одну категорию.

| Значение | Когда использовать |
|---|---|
| agrees | Человек выражает согласие именно с указанным утверждением. |
| disagrees | Человек оспаривает именно это утверждение. |
| acknowledges | Человек подтверждает, что услышал или понял сообщение. |
| accepts_action | Человек соглашается выполнить предложенное действие. |
| unclear | Позиция не выражена, речь о другом предмете либо данных недостаточно. |

Если человек и соглашается действовать, и прямо выражает позицию по утверждению, приоритет имеет позиция. Вопрос о причинах сам по себе не свидетельствует о несогласии. В quote скопируйте короткую дословную цитату из words. Для unclear оставьте поле пустым. После сдачи обеих форм запустите из корня BICA команду `python tools/score_perspective_annotations.py first.csv second.csv`. Она проверит цитаты, посчитает долю совпадений и каппу Коэна и выведет расхождения для совместного разбора.

Параметр `--observations tom_work/results/perspectives_dev_30/observations.jsonl` добавляет сопоставление с агентом на строках, где оба разметчика согласились. Для первичной разметки открыть только пустую форму.
